## Самостоятельная проверка

1. Откройте список и найдите номера 0142200001326018775, 0142200001326018768,
   32616445853, 32616445870, 32616445874.
2. Проверьте поиск по номеру и названию, оба закона, сортировку по цене.
3. Откройте карточки и ссылки «Открыть источник»: адрес ведёт на ЕИС.
4. Проверьте карточку 32616445874: цена не указана. Отсутствующие сведения не вычисляются.
5. Проверьте разделы, узкий экран и масштаб 200%. Ограничения публичного среза
   должны быть понятны, ни одно серверное действие не должно показывать ложный успех.
6. Нажмите «Скопировать ссылку» для конкретного раздела или карточки.
   Напишите замечание: ссылка; экран; шаги; ожидалось; получилось.
   Не указывайте пароли, токены, частные данные или документы.

## Публикация

Этот репозиторий содержит только проверенные статические файлы, их SHA-256 и workflow.
GitHub Actions проверяет все контрольные суммы и публикует каталог `site`.
Исходный проект, его Git-история, закрытые данные и журналы сюда не копируются.
Для повторной публикации используйте workflow dispatch. Для отката восстановите
проверенные `site` и `SHA256SUMS` из нужной предыдущей ревизии и создайте новый commit.
Личная продуктовая приёмка владельца остаётся PENDING.
